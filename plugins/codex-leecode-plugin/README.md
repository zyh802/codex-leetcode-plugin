# Codex LeetCode

在 Codex 里刷力扣：浏览题库、编写代码、运行测试、提交解答，再让 Codex 帮你评审。

插件通过本地 HTTP 页面提供练习工作台，打开在 Codex 右侧 Browser 面板中，不占用对话区。

## 功能

- **浏览题库**：同步力扣中国站题目目录，支持搜索，以及难度、分类、付费、完成状态、收藏筛选。
- **本地编码**：题目与代码分为两个标签页，内置编辑器，解答默认保存在当前工作区。
- **运行与提交**：使用力扣远程判题，展示结果；正式提交前需要确认。
- **代码评审**：将当前题目、代码和判题结果交给 Codex 分析。

## 安装

需要 Node.js 22.22.2 或更新版本（包含 npm）；浏览器登录需要本机安装 Chrome 或 Edge。

1. 在 Codex 的插件页面打开「添加插件市场」。
2. 来源填写下面的仓库名，Git 引用和稀疏路径留空，然后添加市场。
3. 找到「Codex LeetCode」并安装，新开一个任务使用。

```text
zyh802/codex-leetcode-plugin
```

无需手动克隆或构建。首次启动会自动下载本机运行依赖，请保持联网并稍等；后续启动复用本地缓存。

> 市场配置和分发包须已推送到仓库默认分支，本地未推送的修改不会出现在 GitHub 市场中。

## 使用

先对 Codex 说：

```text
打开力扣题库
```

### 登录力扣

浏览公开题库无需登录；运行代码、提交解答，以及查看完成状态、收藏等账号信息前，需要先登录力扣中国站。

1. **找到登录入口**：在工作台左下角点击账号入口，选择「设置」，找到「登录力扣」。
2. **选择是否保存登录**：默认保存到本机系统凭据库，下次打开会自动检查并使用仍有效的登录状态。如果只想临时使用，勾选「仅本次运行，不保存登录凭据」；插件重新启动后需要再次登录。
3. **打开官网窗口**：点击「使用浏览器登录」，插件会启动一个独立的 Chrome 或 Edge 窗口，打开力扣官方登录页。即使日常浏览器已经登录，也需要在这个独立窗口中完成登录。
4. **在官网完成登录**：建议优先使用官网提供的扫码登录，并按手机端提示确认。也可选择官网提供的其他登录方式；密码、短信验证码和安全校验都在官网窗口中完成，无需发送给 Codex。
5. **回到工作台确认结果**：完成登录后稍等，插件会自动验证账号。设置页显示「已登录：你的用户名」即表示成功，可以开始运行和提交代码。验证成功后登录窗口会自动关闭，这是正常行为，无需手动复制 Cookie。

登录遇到问题时：

- **没有弹出窗口**：确认本机已安装 Chrome 或 Edge，再点击「使用浏览器登录」。
- **安全校验反复失败**：验证码登录可能被官网风控拒绝；可改用官网的扫码登录，或稍后重试。插件不会自动完成或绕过安全校验。
- **窗口关闭或等待超时**：回到设置页查看提示，重新发起登录；单次登录最多等待 5 分钟。需要中止时点击「取消登录」。
- **切换账号或登录失效**：切换账号时，在设置页点击「退出登录」，再登录其他账号；会话失效时，重新点击「使用浏览器登录」。退出只清除本机登录会话，题库和解答文件会保留。

#### 高级登录：手动导入 Cookie

当插件的浏览器登录不可用时，可以从自己已登录的力扣中国站浏览器中复制 Cookie，再导入插件。需要先在官网正常完成登录和安全校验。

1. **在日常浏览器登录**：用 Chrome 或 Edge 打开 [力扣中国站](https://leetcode.cn/)，登录自己的账号，确认官网已经显示登录状态。
2. **记录网页请求**：在网页空白处右键 →「检查（Inspect）」，切换到「网络（Network）」标签，再刷新网页。开发者工具打开后才会记录请求。
3. **选中力扣请求**：在请求列表中选择一个已完成、请求地址属于 `https://leetcode.cn/` 的请求，例如 `graphql/`。可在筛选框输入 `domain:leetcode.cn` 缩小范围。
4. **复制 Cookie 值**：打开该请求的「标头（Headers）」→「请求标头（Request Headers）」，找到 `cookie` 或 `Cookie`，复制它的完整值。应同时包含 `LEETCODE_SESSION=...` 和 `csrftoken=...`；只复制这一项的值，不要复制响应中的 `Set-Cookie`、整段请求标头或 cURL 命令。浏览器操作可参考 [Chrome DevTools 请求标头说明](https://developer.chrome.com/docs/devtools/network/reference/#headers)。
5. **粘贴到插件**：回到工作台 → 左下角账号入口 →「设置」。如果浏览器登录仍在等待，先点「取消登录」；如果要更换当前已登录账号，先点「退出登录」。点击「高级登录」，将 Cookie 粘贴到密码样式的输入框；如不想保存，先勾选「仅本次运行，不保存登录凭据」，然后点击「验证并保存」。
6. **确认导入结果**：输入框会立即清空，插件验证会话有效后显示「已登录：你的用户名」，即可运行或提交代码。默认只保存所需的会话字段到本机系统凭据库。

格式示例（以下是占位内容，不能直接用于登录；实际粘贴的值应保持为一行）：

```text
LEETCODE_SESSION=your-session-value; csrftoken=your-csrf-value
```

如果提示缺少字段，检查是否完整复制了同一个请求中的两项值，且来自 `leetcode.cn`，而非国际站 `leetcode.com`。如果提示会话未登录或已失效，请在官网重新登录、刷新网页，再复制新的 Cookie。

Cookie 是登录凭据，只粘贴到插件本地设置页；不要发送到 Codex 对话、Issue、公开截图或代码仓库。

### 开始练习

1. **同步题库**：首次使用，点击左下角账号入口 → 同步题库。
2. **选择题目**：搜索或筛选题目，选择语言，点击「创建代码」。
3. **开始练习**：在「代码」页编写解答，保存后点击「Run」运行测试，确认无误再点击「Submit」提交。

其他常用操作：

- **修改保存目录**：设置 → 解答目录，统一应用于后续新建解答。
- **保存代码**：点击「保存代码」，或按 `⌘/Ctrl + S`。
- **请求评审**：点击「让 Codex 评审」，将复制的提示词粘贴到对话中发送。
- **关闭前端**：设置 → 前端进程 → 关闭本地前端；下次仍可让 Codex 重新打开。

## 数据与安全

- 题目目录保存在本地，题面按需从力扣获取；查看题面和远程判题需要联网。
- 登录凭据保存在本机系统凭据库，不写入代码文件或日志；也可选择「仅本次运行」。
- 已有解答不会在创建时被覆盖；插件不绕过付费题权限，也不自动重复提交。

## 本地开发

```bash
npm install
npm run build
npm run check
```

浏览器测试：`npm run test:e2e`；插件连通性检查：`npm run smoke:mcp`。

发布前执行 `npm run build:marketplace`，将生成的 `plugins/codex-leecode-plugin/` 与源码一起提交。`npm run check:marketplace` 检查分发包是否与源码一致；`npm run smoke:marketplace` 验证全新安装与缓存复用。
